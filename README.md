1. Project Overview

MindMate is a supportive mental wellness chatbot designed to help users who experience emotional stress, anxiety, exam pressure, loneliness, or confusion.
The chatbot interacts in a way that feels like speaking to a gentle and understanding version of your inner self. Instead of giving generic replies, it guides users through calm reflection, grounding exercises, and emotional clarity.
MindMate was developed as part of our academic project to explore AI for mental health support using modern LLM conversational methods.

2. Key Features

Emotion-based responses: Detects user tone and replies empathetically.
Reflective listening: Mirrors user emotions to build trust and connection.
Calming guidance: Provides grounding exercises like breathing, body relaxation, and reassurance.
Progressive questioning: Helps explore the deeper cause of feelings (exam stress, conflicts, loneliness).
User personalization: Remembers the user's name, emotional context, and patterns in conversation.
Crisis safety filter: Detects self-harm intent and responds with supportive but safe messages.
Simple Interface: Runs on Streamlit for fast and clean interaction.

4. Usage

Once running:
Open http://localhost:8501
Enter your name and optionally your current emotional context
(example: “Exam stress”, “Family conflict”, “Feeling lonely”)
Start chatting by typing in the input box

Example Interactions:
User:
“I have an exam tomorrow and I feel panic and can't study.”
Bot:
Reflects emotion + asks a soft, calming question

User:
“I can't stop thinking about failing.”
Bot:
Offers reassurance + guides toward acceptance

User:
“I did the breathing exercise.”
Bot:
Encourages and suggests the next step

User:
“I want to kill myself.”
Bot:
Activates safety response, giving grounding support + directs to real-life help
